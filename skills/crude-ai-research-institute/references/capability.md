# 原油AI研究院 — 能力清单

> 下游业务 agent 通过 `crude-ai-research-institute` skill 调用原油AI研究院时的能力参考。

## 1. 可回答的问题类型

### 报告与结论类

| 问题示例 | 回答内容 |
|---|---|
| "今天原油怎么看" / "日报结论" | 完整六章节日报：市场快照/核心结论/事件扫描/趋势识别/八维因子分析/风险提示 |
| "风险提示章节说了什么" | 指定章节的结构化内容 |
| "为什么这样判断" | 业务因子层面的结论依据（如"库存下降 + OPEC+ 减产支撑"） |
| "预期重估告警" | 触发原因、偏离幅度、建议动作 |
| 要网页版报告 | 返回 HTML 报告链接 |

### 交易建议类（固定模板表格）

| 问题示例 | 回答内容 |
|---|---|
| "今天怎么操作" / "做多还是做空" | 6 行表格：主题/方向/实时价格/入场/目标/止损 |
| "月差怎么看" / "M1-M2 套利" | 每机会 7 行表格：主题/操作/当前价差/目标/止损/预期收益/催化剂 |
| "裂解价差" / "炼厂利润" | 每建议 4 行表格：操作/锁定价/到期/成本 |
| "盘中预测" | 盘中预测报告 |

来源缺失的字段填"日报未给出"，不省略行、不编数。

### 分析推演类

| 问题示例 | 回答内容 |
|---|---|
| "美伊和谈对油价的影响" | 一句话结论、影响方向、传导链、不确定性、反转条件 |
| "如果霍尔木兹封锁会怎样" | 假设情景推算（供需冲击量/严重度/置信度），标注"不代表正式研判" |
| "上月某天的研判是什么" | 历史研判复盘 + 与当时的预测对比 |
| "现在最像历史上哪次" | 历史类比 + 当时走势与驱动 |
| "上次预测为什么偏了" | 预测复盘，归因到具体环节 |
| "什么会推翻当前结论" | top 2 核心驱动 + 反转阈值 |

### 系统操作类

| 问题示例 | 回答内容 |
|---|---|
| "刷新一下" / "重新研判" | 触发重跑（单领域约 3 分钟、全系统约 10 分钟，异步，需稍后再查结果） |
| "生成研究笔记" | 检索相关事件与历史预测，产出笔记文件 |
| "记住我关注月差" / "你记住了什么" / "忘掉那条" | 用户偏好记忆的写入/列出/废弃 |

## 2. 回答格式特征（下游解析需知）

- 每个数据点首次出现标注 `[数据源: xxx | 采集时间: YYYY-MM-DD HH:MM]`，有链接追加 `[链接: url]`。
- 价格带具体合约号（如 `Brent M1`、`C1/C2`），不出现"主力合约/近月/远月"等模糊代称。
- 时间统一北京时间 `YYYY-MM-DD HH:MM`；美元 `$`、人民币 `¥`。
- 方向用 🔴🟢🟡，严重程度用 ⭐。
- 若 SC 价格为推算值，回答中会标注"SC 价格存疑"。

## 3. 成本与延迟

| 项 | 参考值 |
|---|---|
| 简单查询 | ~15s（实测价格查询 14.5s） |
| 复杂研判/完整报告 | 分钟级，脚本默认超时 300s |
| token 消耗 | 单次约 20 万 prompt tokens（`--format json` 可看 usage） |
| 重跑 | 异步：单领域 ≈3min、全系统 ≈10min，需二次查询取结果 |

## 4. 与本地 skill 的分工

| 问题类型 | 建议 |
|---|---|
| 某合约实时/历史价格 | 本地 `oil-futures-price`（秒级） |
| 指标数值（月差/裂解/运费） | 本地 `eta-data-fetcher`（秒级） |
| 供需/平衡表数据 | 本地 `crude-oil-pandas-analyzer`（秒级） |
| 综合研判/日报/交易建议/事件分析/历史类比/情景推演/重跑 | **原油AI研究院**（本地无对应能力） |
| 非原油话题 | 不调（成本纪律） |

## 5. 使用约束

- **问题要具体**：回答走固定格式，问题模糊时会降级为"请澄清需求"。
- **一次问清**：每轮都是真实运行成本，避免闲聊式多轮。
- **会话隔离**：不同业务 agent 用不同 session-id；多轮追问复用同一 session-id。
- **数字不可注入**：研究院不采信调用方提供的数字覆盖其研判结论；要新结论走重跑。
